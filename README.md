# KodeKloud 100 Days of AWS Challenge

A structured, hands-on AWS learning journey where each day focuses on a practical cloud task, real-world AWS problem, and guided solution. The goal is to build strong foundations in AWS services, CLI usage, security, networking, and automation by solving problems step by step.

## What is the KodeKloud 100 Days of AWS Challenge?

The KodeKloud 100 Days of AWS Challenge is a daily learning program designed to help students and professionals practice AWS in a structured and progressive way. Each day introduces a new challenge based on a real AWS use case, such as creating resources, configuring access, securing services, or troubleshooting cloud environments.

The focus is not only on theory but on practical execution. Learners are encouraged to use the AWS CLI, explore services like IAM, EC2, S3, and networking, and understand how these services work together in a real cloud setup.

This repository follows that same learning style by collecting daily challenge files and solutions in one place, making it easier to study, practice, and build confidence over time.

## Why This Repository Exists

This repository is meant to support the KodeKloud AWS challenge by organizing the daily tasks into a clear learning path.

- It helps learners follow the challenge in a structured way.
- It provides step-by-step solutions and explanations.
- It encourages hands-on practice using the AWS CLI.
- It makes it easier to revisit older tasks and learn from them again.
- It acts as a practical AWS learning companion for beginners and aspiring cloud engineers.

## Repository Purpose

The purpose of this repository is to help others learn AWS step by step through realistic exercises and guided solutions.

It is useful for:

- learners following the KodeKloud AWS challenge,
- beginners who want a practical AWS learning path,
- people preparing for AWS fundamentals and cloud operations,
- anyone who wants to improve their AWS CLI and troubleshooting skills.

## Repository Structure

This repo contains daily markdown files, each representing one challenge or solution topic.

```text
.
├── README.md
├── Day 22: Configuring Secure SSH Access to an EC2 Instance.md
├── Day 23: Data Migration Between S3 Buckets Using AWS CLI.md
├── ...
└── additional challenge files as the learning journey continues
```

Each file typically contains:

- the problem statement,
- the business or technical goal,
- the required configuration or command steps,
- and the solution explanation.

## How to Navigate the Repository

To get the most from this project:

1. Start with the README to understand the overall AWS learning flow.
2. Open a day file in order.
3. Read the task carefully and identify which AWS service or concept is involved.
4. Review the solution and command examples.
5. Try to reproduce the task in your own AWS account.
6. Compare your output with the provided example and learn from any differences.

## How to Use This Repo

Follow these steps to practice effectively:

1. Choose a day challenge.
2. Read the problem statement and understand the objective.
3. Identify the AWS resources involved.
4. Follow the solution or recreate the commands in your own environment.
5. Validate the results using AWS CLI outputs or the AWS console.
6. Make notes about what you learned from each task.
7. Move to the next day and continue building your AWS confidence.

> Important: Always use a safe AWS environment and avoid production credentials or resources when practicing.

## Prerequisites

KodeKloud provides a learner-friendly environment for the AWS challenge, so in most cases you do not need to set up your own AWS account from scratch.

Before starting the challenge, it is helpful to have:

- a basic understanding of cloud computing concepts,
- familiarity with Linux command line basics,
- access to the KodeKloud playground or sandbox environment,
- AWS console access provided through the challenge platform,
- AWS CLI access configured in the sandbox environment,
- temporary credentials or role-based access supplied by the platform,
- a browser and terminal environment ready for hands-on practice.

### What KodeKloud provides

In simple words, KodeKloud gives you a playground where you can practice AWS tasks safely. It usually provides:

- a sandbox environment for cloud practice,
- access to AWS console login,
- temporary AWS credentials for CLI access,
- a guided lab or challenge flow,
- a way to experiment without needing your own personal AWS account setup.

This means the challenge is designed to be beginner-friendly: you can focus on learning AWS tasks and commands without worrying about managing your own long-term cloud environment.

## How to Practice the Tasks Yourself

In KodeKloud, the challenge is designed to work in a playground-style environment, so the workflow is usually simple:

1. Log in to the KodeKloud lab or sandbox environment.
2. Open the AWS console or access the terminal provided by the platform.
3. Use the credentials and CLI configuration already supplied by the challenge.
4. Read the problem statement in the relevant day file.
5. Run the commands carefully in the terminal.
6. Verify the expected result using CLI output or the AWS console.
7. Move to the next challenge and continue learning.

If you want to replicate the challenge outside KodeKloud, you can still do so using your own AWS account, but the original KodeKloud model is built around a ready-made playground environment that reduces setup friction for learners.

> Always be mindful of cost and avoid leaving resources running unnecessarily, especially when practicing in a personal AWS account.
